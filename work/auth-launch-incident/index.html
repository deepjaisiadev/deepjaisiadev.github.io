People.com Auth Launch — Incident Response

People Inc. (Formerly Dotdash Meredith)

During the auth platform's first launch on People.com, account routes still resolved to the old, dead app. Diagnosed the layer at fault in a ~50-person war room.

  • ~50 people in the war room
  • 0 rollbacks
  • Recognised the symptom from a near-identical incident months earlier, then confirmed from the served HTML that the new app wasn't being hit at all.
  • Narrowed it to CDN/edge routing (Fastly redirect rules) rather than application code — and pulled in Infra, who hadn't been on the release.
  • Fixed live with no rollback, so the new comments feature stayed up.

Stack: Fastly, CDN / edge routing, Incident response
