Architect — implemented with Claude

A real-time, multi-client notes app in the style of Obsidian/Notion, built in about 10 hours at a work hackathon.

  • ~10 h build time
  • Write-then-broadcast: writes POST to SQLite (source of truth), then the server pushes updates to every client over SSE.
  • Chose SSE over WebSockets — the write path and broadcast path were already separate.
  • Optimistic locking with version checks; the conflict policy depends on the caller (UI prompts the user, MCP retries once).
  • MCP server for AI agents to CRUD notes, revision history, a backlink graph view; one codebase for web and Electron.

Stack: Vue, Electron, SQLite, SSE, MCP
