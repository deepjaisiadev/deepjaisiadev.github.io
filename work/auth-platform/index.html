Auth Platform Rebuild

People Inc. (Formerly Dotdash Meredith)

Sole architect

Rebuilt the login/auth platform's frontend so every brand site tracks the current core platform instead of lagging behind on stale published packages.

  • −50% bundle size
  • −30% CI/CD deploy time
  • 45+ brand sites
  • 20M+ DAU
  • Moved the platform from an npm-dependency model to a git-dependency model — sites pull directly against current source, and the separate publish and hosting step is gone.
  • Each site's build package went from ~100 files (the whole project) to the ~15 config/SCSS files it actually needs.
  • Onboarded 5 sites — including Investopedia and the People app — ahead of a hard quarterly deadline, without waiting on a cross-team CI/CD change.
  • Wrote an onboarding skill and AGENTS.md documentation, plus a shared Slack channel; onboarding became mostly self-serve for other engineers.

Stack: Keycloak, SCSS, Gradle, Git dependencies, CI/CD
