The RAG pipeline behind an internal agent, over the core platform's documentation and internal framework docs. Started as a work hackathon project.

  • 1st place (tied)
  • Vectorized the documentation and framework docs into Pinecone, so the agent pulls precise answers with fewer tokens.
  • Tied for first place at the hackathon; now used daily by the engineering team.
  • Tracked usage and cost per request (chunks retrieved, context size); a proper quality evaluation — golden set, retrieval precision, groundedness — is the next step.

Stack: RAG, LLMs, Pinecone, Vector search
