Hackathons

Owned the entire client and data-serving layer

A live crowd-density platform for NYC that fuses permitted-events data with public DOT traffic cameras — a Gemini chat agent plus a real-time heatmap dashboard. NYC Vision Hack v2 (Google Cloud × Roboflow × Veris).

  • 33 h build window
  • 968 cameras
  • 16 zones
  • When Google deprecated HeatmapLayer mid-build, wrote a replacement from scratch: a canvas OverlayView with Gaussian-blob accumulation and a 256-entry colour lookup table, with zero added dependencies.
  • Real-time geospatial aggregation: each camera assigned to the nearest of 16 neighbourhood zones, with “× usual” density ratios against multi-day baselines.
  • Auth bridge to an IAM-gated Cloud Run service using GCP metadata-server identity tokens, proxying SSE agent responses and camera frames — shipped as one Docker deploy.

Stack: React, Google Maps JS API, Canvas, Node.js, Express, GCP Cloud Run, SSE, Docker
